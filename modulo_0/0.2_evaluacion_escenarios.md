# EVALUACIÓN DE ESCENARIOS

**Tiempo estimado**: 60 minutos
**Nivel**: Básico
**Prerrequisitos**: Tema 0.1 (Regla de los Tres, OODA, Control del pánico)

---

## ¿Por qué importa este concepto?

Una vez que has controlado tu respuesta de pánico y entiendes las prioridades de supervivencia, necesitas un método sistemático para **evaluar tu situación específica**. Cada escenario de supervivencia es único, y las decisiones correctas dependen de un análisis preciso de tus recursos, amenazas y opciones.

La evaluación de escenarios transforma el conocimiento teórico en acción práctica. Sin ella, puedes conocer perfectamente la Regla de los Tres pero aún así tomar decisiones incorrectas porque no evaluaste bien tu situación particular.

---

## Conexión con conocimientos previos

Este tema aplica directamente el Ciclo OODA: las fases de Observar y Orientar se convierten en un proceso estructurado de evaluación. También conecta con la Regla de los Tres, ya que la evaluación debe identificar cuál de las prioridades es más urgente en tu situación específica.

# SUBTEMA 0.2.1: SWOT DE SUPERVIVENCIA

## Comprensión intuitiva

El análisis SWOT (Strengths, Weaknesses, Opportunities, Threats) es una herramienta de planificación estratégica adaptada para supervivencia. Te permite categorizar rápidamente tu situación en cuatro cuadrantes que guían tus decisiones.

En español, usaremos **FODA** (Fortalezas, Oportunidades, Debilidades, Amenazas), pero mantendremos la estructura original que diferencia factores internos (sobre ti) y externos (sobre el entorno).

### La matriz SWOT de supervivencia

```
                    FACTORES POSITIVOS    FACTORES NEGATIVOS
                    ═══════════════════    ═══════════════════
FACTORES INTERNOS   FORTALEZAS (S)        DEBILIDADES (W)
(Sobre ti)          ¿Qué habilidades      ¿Qué me falta?
                    tengo? ¿Qué llevo?    ¿Qué limitaciones
                    ¿Cómo estoy?          tengo?

FACTORES EXTERNOS   OPORTUNIDADES (O)     AMENAZAS (T)
(Sobre el entorno)  ¿Qué recursos hay?    ¿Qué peligros hay?
                    ¿Qué me puede         ¿Qué puede empeorar
                    ayudar?               mi situación?
```

### Ejemplo motivador

**Escenario**: Tu vehículo se ha averiado en una carretera rural. No hay señal de celular. Es mediodía de verano.

**Análisis SWOT rápido**:

| FORTALEZAS (S)                  | DEBILIDADES (W)                |
| ------------------------------- | ------------------------------ |
| Tengo 2L de agua en el coche    | No sé mecánica                 |
| Llevo ropa adecuada             | Estoy solo                     |
| Conozco la zona aproximadamente | No avisé a nadie mi ruta       |
| Tengo un encendedor             | Mi condición física es regular |

| OPORTUNIDADES (O)           | AMENAZAS (T)                 |
| --------------------------- | ---------------------------- |
| Hay sombra bajo los árboles | Calor intenso (38°C)         |
| La carretera es transitada  | Se acerca la noche           |
| Hay una gasolinera a 8km    | Animales salvajes en la zona |
| El coche tiene batería      | Tormentas pronosticadas      |

**Decisiones basadas en SWOT**:

- Usar FORTALEZA (agua) para mitigar AMENAZA (calor)
- Aprovechar OPORTUNIDAD (sombra) mientras espero
- Compensar DEBILIDAD (no mecánica) esperando ayuda en lugar de intentar reparar
- Mitigar AMENAZA (noche) señalizando el vehículo antes de que oscurezca

## Definición formal

### Categorías del análisis SWOT de supervivencia

#### FORTALEZAS (Strengths) - Factores internos positivos

Todo lo que **posees o controlas** que puede ayudarte:

| Categoría               | Ejemplos                                        |
| ----------------------- | ----------------------------------------------- |
| **Conocimientos**       | Primeros auxilios, orientación, idiomas locales |
| **Habilidades**         | Natación, escalada, conducción todoterreno      |
| **Equipo**              | Cuchillo, encendedor, brújula, cuerda           |
| **Condición física**    | Buena salud, resistencia, fuerza                |
| **Estado mental**       | Calma, determinación, experiencia previa        |
| **Recursos corporales** | Ropa adecuada, calzado resistente               |

#### DEBILIDADES (Weaknesses) - Factores internos negativos

Todo **sobre ti** que puede perjudicarte:

| Categoría                  | Ejemplos                              |
| -------------------------- | ------------------------------------- |
| **Limitaciones físicas**   | Lesiones, enfermedades, baja forma    |
| **Carencias de equipo**    | Sin cuchillo, sin agua, sin abrigo    |
| **Falta de conocimientos** | No sé nadar, no conozco plantas       |
| **Estado mental**          | Miedo, depresión, falta de motivación |
| **Dependencias**           | Medicamentos, gafas, audífonos        |

#### OPORTUNIDADES (Opportunities) - Factores externos positivos

Todo **en el entorno** que puede beneficiarte:

| Categoría                   | Ejemplos                                    |
| --------------------------- | ------------------------------------------- |
| **Recursos naturales**      | Agua potable, frutos, caza                  |
| **Refugio natural**         | Cuevas, árboles densos, formaciones rocosas |
| **Señales de civilización** | Caminos, tendido eléctrico, humo            |
| **Clima favorable**         | Temperatura moderada, sin lluvia            |
| **Fauna útil**              | Peces, aves comestibles                     |
| **Ayuda potencial**         | Tráfico cercano, vuelos, actividad humana   |

#### AMENAZAS (Threats) - Factores externos negativos

Todo **en el entorno** que puede dañarte:

| Categoría           | Ejemplos                                      |
| ------------------- | --------------------------------------------- |
| **Clima**           | Frío extremo, calor, tormentas, lluvia        |
| **Fauna peligrosa** | Depredadores, serpientes, insectos            |
| **Terreno**         | Precipicios, ríos crecidos, terreno inestable |
| **Tiempo**          | Oscuridad inminente, estación cambiante       |
| **Aislamiento**     | Distancia a civilización, sin cobertura móvil |
| **Otros humanos**   | Zonas de conflicto, criminalidad              |

## Casos de estudio

### Caso 1: Perdido en bosque templado (primavera)

**FORTALEZAS**:

- Cuchillo multiusos
- Encendedor (medio lleno)
- 500ml de agua
- Conocimiento básico de plantas
- Buena condición física

**DEBILIDADES**:

- Sin mapa ni brújula
- Ropa ligera (solo camiseta)
- Sin comida
- No sé exactamente dónde estoy
- Nadie sabe mi ubicación

**OPORTUNIDADES**:

- Arroyo visible a 200m
- Muchos árboles caídos (refugio potencial)
- Temperatura moderada (15°C)
- Horas de luz restantes (~4h)
- Sonido de carretera (dirección este)

**AMENAZAS**:

- Noche fría pronosticada (5°C)
- Lluvia posible mañana
- Terreno irregular
- Oscuridad en 4 horas

**Análisis y decisión**:

1. **Amenaza prioritaria**: Frío nocturno (5°C) con ropa ligera = riesgo de hipotermia
2. **Estrategia S+T**: Usar encendedor (F) para contrarrestar frío (A)
3. **Estrategia W+O**: Sin abrigo (D) pero hay madera (O) = construir refugio aislante
4. **Plan de acción**:
   - Próxima hora: Construir refugio de escombros usando árboles caídos
   - Antes de oscurecer: Preparar fogata con leña seca
   - Mañana: Caminar hacia sonido de carretera (este)
   - NO intentar caminar de noche (evitar D+T: no conozco terreno + oscuridad)

## Errores frecuentes

### Error 1: SWOT incompleto

**Situación**: Persona que solo evalúa amenazas y debilidades, entrando en modo catastrofista.

**Por qué falla**: Ignora recursos disponibles que podrían resolver su situación. El pesimismo selectivo paraliza la acción.

**Solución correcta**: Forzarte a encontrar al menos 3 elementos en CADA cuadrante antes de planificar.

### Error 2: Sobrevalorar fortalezas

**Situación**: "Tengo un curso de supervivencia, puedo con esto" - ignorando amenazas reales.

**Por qué falla**: El exceso de confianza lleva a subestimar riesgos. La experiencia en entorno controlado no equivale a capacidad en emergencia real.

**Solución correcta**: Evaluar fortalezas honestamente. ¿He practicado esta habilidad recientemente? ¿En condiciones similares?

### Error 3: Análisis demasiado largo

**Situación**: Persona haciendo SWOT detallado mientras oscurece y la temperatura baja.

**Por qué falla**: El análisis es herramienta, no fin. Gastar demasiado tiempo analizando reduce el tiempo para actuar.

**Solución correcta**: SWOT de 5 minutos máximo. Mejor un análisis 80% correcto en 5 minutos que uno 100% correcto en 30 minutos cuando ya es de noche.

---

## Resumen del concepto

**En una frase**: SWOT categoriza tu situación en fortalezas, debilidades, oportunidades y amenazas para tomar decisiones basadas en datos.

**Cuándo usarlo**: Inmediatamente después de controlar el pánico, como parte de la fase Orientar del OODA.

**Prerequisito crítico**: Control emocional suficiente para evaluar objetivamente.

**Siguiente paso**: Kit de los 10 Esenciales - equipamiento que convierte debilidades en fortalezas.

# SUBTEMA 0.2.2: EL KIT DE LOS 10 ESENCIALES

## Comprensión intuitiva

El Kit de los 10 Esenciales es una lista de categorías de equipamiento desarrollada por The Mountaineers (organización de montañismo de Seattle) en los años 1930. Ha sido actualizada múltiples veces, pero su principio se mantiene: **estas 10 categorías cubren las necesidades básicas de supervivencia en casi cualquier escenario**.

No es una lista de 10 objetos específicos, sino de **10 sistemas funcionales**. Cada sistema puede implementarse de múltiples formas según el contexto.

### Los 10 Sistemas Esenciales

```
LOS 10 ESENCIALES (Versión Sistemas)
═══════════════════════════════════════════════════════════════

1. NAVEGACIÓN        Saber dónde estás y hacia dónde ir
2. ILUMINACIÓN       Ver y ser visto en oscuridad
3. PROTECCIÓN SOLAR  Prevenir quemaduras y deshidratación
4. PRIMEROS AUXILIOS Tratar lesiones y enfermedades
5. HERRAMIENTA       Cortar, reparar, improvisar
6. FUEGO             Calor, señalización, purificación
7. REFUGIO           Protección contra elementos
8. ALIMENTACIÓN      Energía para funcionar
9. HIDRATACIÓN       Agua suficiente y potabilización
10. EMERGENCIA       Equipo para situaciones imprevistas

═══════════════════════════════════════════════════════════════
```

### Ejemplo motivador

Imagina que llevas solo tu celular y cartera en una excursión "corta" de 2 horas. El sendero está cerrado por derrumbe y debes dar un rodeo. Oscurece antes de que salgas.

**Sin los 10 esenciales**:

- Sin navegación: No sabes el camino alternativo
- Sin luz: No puedes ver el sendero
- Sin abrigo: El frío nocturno te afecta
- Sin agua extra: Te deshidratas
- Sin primeros auxilios: Un rasguño puede infectarse

**Con los 10 esenciales** (versión mínima de 2kg):

- Mapa y brújula: Encuentras ruta alternativa
- Frontal: Ves el camino
- Capa impermeable: Te proteges del frío
- Botella y pastillas purificadoras: Bebes agua del arroyo
- Botiquín: Tratas cualquier lesión menor

El kit de 2kg te da opciones. Sin él, dependes de la suerte.

## Definición formal

### Sistema 1: Navegación

**Función**: Determinar ubicación y dirección de viaje.

| Componente       | Uso                              | Peso aprox.         |
| ---------------- | -------------------------------- | ------------------- |
| Mapa topográfico | Ubicación, planificación de ruta | 50g                 |
| Brújula          | Orientación, navegación          | 30g                 |
| GPS/App offline  | Respaldo electrónico             | (ya llevas celular) |
| Altímetro        | Ubicación por altitud            | 20g (opcional)      |

**Mínimo absoluto**: Mapa + brújula básica.

### Sistema 2: Iluminación

**Función**: Visión y señalización en oscuridad.

| Componente           | Uso                       | Peso aprox.    |
| -------------------- | ------------------------- | -------------- |
| Linterna frontal     | Manos libres, caminar     | 80g            |
| Baterías extra       | Autonomía extendida       | 50g            |
| Linterna de respaldo | Backup si falla principal | 30g (opcional) |

**Mínimo absoluto**: Frontal con baterías frescas.

### Sistema 3: Protección Solar

**Función**: Prevenir daño por radiación UV.

| Componente             | Uso                                          | Peso aprox.    |
| ---------------------- | -------------------------------------------- | -------------- |
| Gafas de sol           | Protección ocular, previene ceguera de nieve | 30g            |
| Protector solar SPF30+ | Prevenir quemaduras                          | 50g            |
| Ropa de manga larga    | Protección física                            | (ya la llevas) |
| Sombrero/gorra         | Protección facial y cabeza                   | 80g            |

**Mínimo absoluto**: Gafas + protector solar.

### Sistema 4: Primeros Auxilios

**Función**: Tratar lesiones y condiciones médicas.

| Componente          | Uso                          | Peso aprox. |
| ------------------- | ---------------------------- | ----------- |
| Vendas/gasas        | Cubrir heridas               | 30g         |
| Cinta adhesiva      | Fijar vendajes, ampollas     | 20g         |
| Antiséptico         | Desinfectar heridas          | 30g         |
| Analgésicos         | Dolor, fiebre                | 10g         |
| Medicación personal | Condiciones crónicas         | variable    |
| Pinzas              | Extraer astillas, garrapatas | 10g         |

**Mínimo absoluto**: Vendas + cinta + antiséptico.

### Sistema 5: Herramienta (Cuchillo/Multiusos)

**Función**: Cortar, reparar, construir.

| Componente        | Uso                                  | Peso aprox. |
| ----------------- | ------------------------------------ | ----------- |
| Cuchillo fijo     | Corte robusto, batoning              | 150-300g    |
| Navaja multiusos  | Versatilidad, herramientas múltiples | 80-150g     |
| Kit de reparación | Cinta, alambre, aguja e hilo         | 50g         |

**Mínimo absoluto**: Cuchillo o navaja de calidad.

### Sistema 6: Fuego

**Función**: Calor, cocción, señalización, purificación de agua.

| Componente             | Uso                             | Peso aprox. |
| ---------------------- | ------------------------------- | ----------- |
| Encendedor             | Ignición fácil                  | 20g         |
| Cerillas impermeables  | Respaldo                        | 10g         |
| Ferrocerio (firesteel) | Respaldo duradero               | 30g         |
| Yesca preparada        | Ignición en condiciones húmedas | 20g         |

**Mínimo absoluto**: Encendedor + respaldo (cerillas o ferrocerio).

### Sistema 7: Refugio/Protección

**Función**: Aislamiento de elementos climáticos.

| Componente              | Uso                              | Peso aprox. |
| ----------------------- | -------------------------------- | ----------- |
| Manta de emergencia     | Retención de calor, señalización | 50g         |
| Poncho/capa impermeable | Lluvia, viento                   | 150g        |
| Bolsa de vivac          | Refugio de emergencia completo   | 200g        |
| Cordaje (paracord)      | Construcción de refugio          | 50g (5m)    |

**Mínimo absoluto**: Manta de emergencia + capa impermeable.

### Sistema 8: Alimentación

**Función**: Energía calórica para funcionamiento corporal.

| Componente           | Uso                                  | Peso aprox. |
| -------------------- | ------------------------------------ | ----------- |
| Barritas energéticas | Calorías concentradas, no perecedero | 100g (x2)   |
| Frutos secos/mezcla  | Energía sostenida                    | 100g        |
| Gel energético       | Energía rápida                       | 50g         |

**Mínimo absoluto**: Comida para 1 día extra (500-800 kcal).

### Sistema 9: Hidratación

**Función**: Agua para funciones corporales.

| Componente              | Uso                            | Peso aprox. |
| ----------------------- | ------------------------------ | ----------- |
| Botella/cantimplora     | Transporte de agua             | 100g (1L)   |
| Sistema de purificación | Hacer agua potable             | variable    |
| - Pastillas (Micropur)  | Ligeras, fáciles               | 20g         |
| - Filtro                | Rápido, sabor neutro           | 80-200g     |
| - Hervido               | Sin peso extra si tienes fuego | 0g          |

**Mínimo absoluto**: 1L de capacidad + método de purificación.

### Sistema 10: Emergencia

**Función**: Comunicación, señalización, situaciones imprevistas.

| Componente        | Uso                                  | Peso aprox. |
| ----------------- | ------------------------------------ | ----------- |
| Silbato           | Señalización audible (alcance 1.5km) | 10g         |
| Espejo de señales | Señalización visual (alcance +15km)  | 20g         |
| Cordaje extra     | Múltiples usos                       | 30g         |
| Cinta americana   | Reparaciones universales             | 30g         |

**Mínimo absoluto**: Silbato + espejo de señales.

## Errores frecuentes

### Error 1: Llevar equipo sin saber usarlo

**Situación**: Persona con kit completo que no sabe usar la brújula ni encender fuego.

**Por qué falla**: El equipo es inútil sin habilidad. Una brújula no te orienta si no sabes interpretarla.

**Solución correcta**: Practica con cada elemento de tu kit en condiciones controladas antes de necesitarlo.

### Error 2: Kit demasiado pesado

**Situación**: Kit de 10kg que terminas dejando en casa o en el coche porque "pesa mucho".

**Por qué falla**: El mejor kit es el que llevas contigo. Un kit ligero siempre presente es mejor que uno completo que dejas.

**Solución correcta**: Empieza con kit mínimo (~1.5kg). Mejor tenerlo siempre que tener uno perfecto nunca.

### Error 3: Confiar solo en electrónicos

**Situación**: "Tengo GPS en el celular, no necesito mapa ni brújula".

**Por qué falla**: Baterías se agotan, pantallas se rompen, señal falla. Los sistemas electrónicos son respaldo, no sistema principal.

**Solución correcta**: Siempre lleva sistema analógico (mapa + brújula) como principal. Electrónicos son respaldo.
