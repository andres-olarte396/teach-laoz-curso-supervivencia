# HERRAMIENTAS LÍTICAS

**Tiempo estimado**: 90 minutos (teoría) + 120 minutos (práctica)
**Nivel**: Intermedio
**Prerrequisitos**: Módulo 1 completo

---

## ¿Por qué importa este concepto?

Durante millones de años, las herramientas de piedra fueron la tecnología dominante de la humanidad. Los principios de la talla lítica siguen siendo relevantes porque:

1. **Las rocas están en todas partes**: A diferencia del metal, la piedra está disponible globalmente
2. **No requiere fuego ni metalurgia**: Puedes fabricar herramientas con tus manos
3. **Bordes extremadamente afilados**: Una lasca de obsidiana puede ser más afilada que un bisturí de acero
4. **Conocimiento que no se agota**: Una vez aprendido, puedes crear herramientas indefinidamente

---

## Conexión con conocimientos previos

Las herramientas líticas complementan las habilidades del Módulo 1:
- **Fuego**: Un cuchillo de piedra ayuda a preparar yesca y procesar madera
- **Refugio**: Herramientas para cortar ramas y materiales
- **Agua**: Recipientes tallados para hervir con piedras calientes
- **Alimento**: Procesamiento de carne, plantas y pescado

# SUBTEMA 2.1.1: SELECCIÓN DE MATERIALES

## Comprensión intuitiva

No todas las rocas son aptas para tallar. Las mejores tienen una estructura **vítrea y homogénea** que permite fractura controlada. Cuando golpeas una roca adecuada, la fractura se propaga de forma predecible (fractura concoidea), creando bordes afilados.

### Rocas aptas para talla

```
MATERIALES DE TALLA - CLASIFICACIÓN
═══════════════════════════════════════════

TIER 1: EXCELENTES
─────────────────────────────────────────
• OBSIDIANA
  - Color: Negro brillante, translúcido
  - Origen: Volcánico (vidrio natural)
  - Filo: El más afilado posible
  - Dureza: 5-5.5 Mohs
  - Localización: Zonas volcánicas

• SÍLEX / PEDERNAL (Flint)
  - Color: Gris, negro, marrón, crema
  - Origen: Sedimentario (nódulos en caliza)
  - Filo: Excelente
  - Dureza: 6.5-7 Mohs
  - Localización: Formaciones calizas, playas

TIER 2: BUENOS
─────────────────────────────────────────
• CUARZO
  - Color: Blanco lechoso a transparente
  - Origen: Cristalino
  - Filo: Bueno, pero impredecible
  - Dureza: 7 Mohs
  - Localización: Muy común globalmente

• JASPE
  - Color: Rojo, marrón, amarillo
  - Origen: Sedimentario silíceo
  - Filo: Muy bueno
  - Dureza: 6.5-7 Mohs
  - Localización: Lechos de ríos, zonas volcánicas

• CALCEDONIA
  - Color: Variable, translúcido
  - Origen: Silíceo criptocristalino
  - Filo: Excelente
  - Dureza: 6.5-7 Mohs

TIER 3: FUNCIONALES
─────────────────────────────────────────
• CUARCITA
  - Color: Blanco, gris, rosado
  - Origen: Metamórfico
  - Filo: Aceptable, más grueso
  - Dureza: 7 Mohs
  - Localización: Muy común

• BASALTO (de grano fino)
  - Color: Gris oscuro a negro
  - Origen: Volcánico
  - Filo: Funcional pero burdo
  - Dureza: 6 Mohs


ROCAS NO APTAS
─────────────────────────────────────────
✗ Granito (demasiado granular)
✗ Arenisca (se desmorona)
✗ Pizarra (se lamina, no fractura)
✗ Mármol (demasiado blando)
✗ Cualquier roca porosa o con granos visibles
```

### Test de aptitud para talla

```
EVALUACIÓN DE ROCA PARA TALLA
═══════════════════════════════════════════

TEST 1: SONIDO
─────────────────────────────────────────
Golpear la roca contra otra.
✓ Sonido agudo, "ting" metálico = BUENA
✗ Sonido sordo, "clunk" = NO APTA

TEST 2: FRACTURA
─────────────────────────────────────────
Romper un fragmento pequeño.
✓ Superficie lisa, brillante, curva = BUENA
✗ Superficie granular o irregular = NO APTA

TEST 3: HOMOGENEIDAD
─────────────────────────────────────────
Examinar sección transversal.
✓ Color y textura uniformes = BUENA
✗ Vetas, inclusiones, bandas = MALA calidad

TEST 4: DUREZA (test de rayado)
─────────────────────────────────────────
Intentar rayar vidrio con la roca.
✓ Raya el vidrio = Suficientemente dura
✗ No raya = Demasiado blanda
```

# SUBTEMA 2.1.2: TALLA POR PERCUSIÓN DIRECTA

## Comprensión intuitiva

La percusión directa es el método más básico: golpear una roca (núcleo) con otra (percutor) para desprender fragmentos afilados (lascas). Es la técnica que usaron los primeros homínidos hace 2.6 millones de años.

### Principios de la fractura concoidea

```
MECÁNICA DE LA FRACTURA CONCOIDEA
═══════════════════════════════════════════

Cuando golpeas cerca del borde de una roca vítrea,
la onda de choque se propaga en forma de cono,
desprendiendo una lasca con forma de concha.

        PERCUTOR
           │
           │ Golpe
           ▼
    ┌──────●──────┐
    │      │      │
    │      │      │  ← NÚCLEO
    │      │      │
    │      ╲     │
    │       ╲    │
    │        ╲   │
    │         ╲  │
    │          ╲ │
    └───────────╲│
                 ╲
                  ╲ ← LASCA desprendida
                   (forma de concha)


CARACTERÍSTICAS DE LA LASCA:
• Bulbo de percusión (protuberancia donde golpeaste)
• Ondas de propagación (como ondas en agua)
• Borde afilado (el filo útil)
• Cara ventral (lisa) y dorsal (corteza o lascados previos)
```

### Técnica de percusión

```
TÉCNICA DE PERCUSIÓN DIRECTA
═══════════════════════════════════════════

POSICIÓN:
• Sentado con piernas cruzadas o en cuclillas
• Núcleo apoyado en el muslo o sostenido
• Percutor en mano dominante

PERCUTOR:
• Piedra redondeada, del tamaño de un huevo
• Densa y resistente (granito, cuarcita)
• Sin aristas que puedan lastimarte

ÁNGULO DE GOLPE:
                  │
                  │ Percutor
                  │
            ╲     │
             ╲    │
              ╲   │  ← Ángulo ~60°
               ╲  │     respecto a
                ╲ │     la superficie
    ═════════════╲│
         Plataforma de golpeo


PASOS:

1. PREPARAR PLATAFORMA
   - Identificar o crear superficie plana
   - Ángulo menor a 90° respecto a la cara
   - Sin irregularidades

2. POSICIONAR
   - Golpe cerca del borde, no en el centro
   - Distancia del borde: 5-15mm
   - Dirección: Hacia la cara que quieres lascar

3. GOLPEAR
   - Movimiento de muñeca, no de brazo
   - Golpe seco y preciso
   - Seguir el golpe (no detener el percutor)

4. EVALUAR
   - ¿Se desprendió lasca?
   - ¿El borde es afilado?
   - Repetir ajustando ángulo y fuerza
```

## Implementación práctica

### Producción de lascas simples

```
EJERCICIO: PRIMERAS LASCAS
═══════════════════════════════════════════

MATERIALES:
• Nódulo de sílex o cuarzo (tamaño puño)
• Percutor de piedra redondeada
• Gafas de protección (OBLIGATORIO)
• Guantes de cuero (recomendado)
• Lona para recoger lascas

OBJETIVO: Producir 5 lascas utilizables

PROCEDIMIENTO:

1. Examinar el núcleo
   - Identificar plataformas naturales
   - Planificar secuencia de extracción

2. Primera lasca
   - Elegir el punto más prometedor
   - Golpe controlado, no demasiado fuerte
   - Observar resultado

3. Ajustar según resultado:

   PROBLEMA → SOLUCIÓN
   ─────────────────────────────────────
   Lasca muy pequeña → Golpe más fuerte
   Lasca se fragmenta → Ángulo más agudo
   No sale lasca → Cambiar plataforma
   Lasca muy gruesa → Golpe más cerca del borde

4. Repetir hasta obtener 5 lascas afiladas

CRITERIOS DE ÉXITO:
□ Lasca de al menos 4cm de largo
□ Borde afilado (corta papel)
□ Sin fracturas secundarias
```

```
PRECAUCIONES EN TALLA LÍTICA
═══════════════════════════════════════════

⚠️ PROTECCIÓN OCULAR
   Las esquirlas de piedra son EXTREMADAMENTE
   peligrosas para los ojos.
   SIEMPRE usar gafas de protección.

⚠️ PROTECCIÓN DE MANOS
   Los bordes son más afilados que vidrio.
   Usar guantes de cuero o proteger palma
   con tela gruesa.

⚠️ POSICIÓN DEL CUERPO
   Mantener núcleo alejado del cuerpo.
   Las lascas pueden salir en direcciones
   impredecibles.

⚠️ LIMPIEZA
   Las esquirlas pequeñas son invisibles
   pero cortantes.
   Trabajar sobre lona, limpiar después.

⚠️ CORTES
   Ten primeros auxilios a mano.
   Los cortes de obsidiana son profundos
   y sangran mucho (tan afilada que no duele).
```

# SUBTEMA 2.1.3: FABRICACIÓN DE CUCHILLO Y RASPADOR

## Comprensión intuitiva

Una lasca en bruto ya es una herramienta, pero puede mejorarse mediante **retoque**: pequeños golpes que modifican el borde para hacerlo más funcional o duradero.

### Tipos de herramientas básicas

```
HERRAMIENTAS LÍTICAS FUNDAMENTALES
═══════════════════════════════════════════

1. CUCHILLO (lasca con filo)
─────────────────────────────────────────
   Uso: Cortar carne, plantas, cuerdas
   Forma: Lasca alargada con un borde afilado

        ╱╲
       ╱  ╲
      ╱    ╲ ← Borde afilado
     ╱      ╲
    ╱        ╲
   ╱__________╲ ← Borde romo (para sujetar)


2. RASPADOR (scraper)
─────────────────────────────────────────
   Uso: Procesar pieles, raspar madera
   Forma: Lasca gruesa con borde reforzado

       ┌────────┐
       │        │
       │        │
       │        │
       └────────┘
            │
            ▼
       ╭────────╮ ← Borde redondeado
                    y reforzado


3. PERFORADOR (buril)
─────────────────────────────────────────
   Uso: Hacer agujeros en cuero, madera
   Forma: Punta resistente

          ╱╲
         ╱  ╲
        ╱    ╲
       ╱      ╲
      │        │
      │        │


4. HACHA DE MANO (bifaz)
─────────────────────────────────────────
   Uso: Multiherramienta prehistórica
   Forma: Tallada por ambas caras

         ╱╲
        ╱  ╲
       ╱    ╲
      ╱      ╲
      ╲      ╱
       ╲    ╱
        ╲  ╱
         ╲╱
```

### Técnica de retoque

```
RETOQUE POR PRESIÓN
═══════════════════════════════════════════

El retoque por presión permite control fino
del borde, imposible con percusión.

HERRAMIENTA:
• Punta de asta de ciervo
• Punta de hueso
• Clavo grueso con mango

TÉCNICA:

1. Apoyar la lasca firmemente
   (en la palma protegida o sobre madera)

2. Posicionar la punta del retocador
   en el borde, ligeramente por debajo

3. Aplicar presión hacia afuera y abajo
   simultáneamente

4. Una pequeña lasca se desprende,
   creando un "mordisco" en el borde

        RETOCADOR
             │
             ▼
    ┌────────●────────┐
    │         ╲       │
    │          ╲      │  LASCA
    │           ╲     │
    │            ╲    │
    │             ╲   │
    └──────────────╲──┘
                    ╲
                     ╲ pequeña lasca
                       desprendida

5. Repetir a lo largo del borde
   para crear filo continuo

RESULTADO:
   Borde original     Borde retocado
   ═══════════════    ╭─╮╭─╮╭─╮╭─╮
                      │ ││ ││ ││ │
                      (dentado fino)
```

## Enmangado básico

```
ENMANGAR UNA LASCA
═══════════════════════════════════════════

Un mango multiplica la utilidad de la herramienta
y protege la mano.

MÉTODO 1: INSERCIÓN EN RANURA
─────────────────────────────────────────

1. Encontrar rama de madera verde (15-25cm)
2. Hacer ranura longitudinal con otra piedra
3. Insertar lasca en la ranura
4. Atar con cordaje o tendones

        ┌─────────┐
        │  MANGO  │
        │         │
        │    │    │ ← Ranura
        │    │    │
        │ ┌──┴──┐ │
        │ │LASCA│ │
        │ └─────┘ │
        └═════════┘ ← Atadura


MÉTODO 2: PEGAMENTO NATURAL + ATADURA
─────────────────────────────────────────

1. Preparar resina de pino caliente
2. Aplicar resina al mango y la lasca
3. Unir y mantener mientras enfría
4. Reforzar con atadura

ADHESIVOS NATURALES:
• Resina de pino (calentar hasta líquida)
• Brea de abedul (complejo de preparar)
• Mezcla de resina + carbón molido
```
