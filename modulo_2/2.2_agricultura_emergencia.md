# AGRICULTURA DE EMERGENCIA

**Tiempo estimado**: 60 minutos (teoría) + práctica continua
**Nivel**: Intermedio
**Prerrequisitos**: Tema 1.4 (Alimentación)

---

## ¿Por qué importa este concepto?

La agricultura de emergencia es relevante para **supervivencia prolongada** (semanas a meses). Cuando la recolección y caza no son suficientes, cultivar alimentos básicos puede marcar la diferencia entre sobrevivir y prosperar.

# SUBTEMA 2.2.1: IDENTIFICACIÓN DE SUELOS FÉRTILES

## Indicadores de suelo productivo

```
EVALUACIÓN RÁPIDA DE SUELO
═══════════════════════════════════════════

CARACTERÍSTICAS DE BUEN SUELO:
✓ Color oscuro (materia orgánica)
✓ Textura esponjosa, no compactado
✓ Presencia de lombrices
✓ Vegetación natural abundante
✓ Retiene humedad sin encharcarse
✓ Olor a "tierra mojada" (petricor)

CARACTERÍSTICAS DE SUELO POBRE:
✗ Color gris claro o rojizo
✗ Textura arenosa o arcillosa pura
✗ Sin vida visible
✗ Compactado, duro
✗ Se encharca o seca muy rápido


TEST DE TEXTURA (30 segundos):
─────────────────────────────────────────
1. Tomar puñado de tierra húmeda
2. Apretar en la mano
3. Abrir la mano:
   • Se desmorona = Demasiado arenoso
   • Mantiene forma, se rompe al tocar = IDEAL
   • Mantiene forma pegajosa = Demasiado arcilloso
```

# SUBTEMA 2.2.3: RECOLECCIÓN Y ALMACENAMIENTO DE SEMILLAS

## Principios de conservación de semillas

```
RECOLECCIÓN DE SEMILLAS
═══════════════════════════════════════════

1. MOMENTO ÓPTIMO
   • Esperar madurez completa
   • Semillas duras y coloreadas
   • Fruto/vaina seca en la planta

2. SECADO
   • Secar a la sombra (no sol directo)
   • Buena ventilación
   • 1-2 semanas hasta estar crujientes

3. ALMACENAMIENTO
   • Recipiente hermético
   • Lugar fresco y oscuro
   • Evitar humedad

4. VIABILIDAD
   • La mayoría: 2-5 años
   • Legumbres: 3-4 años
   • Cebollas/zanahorias: 1-2 años


SEMILLAS PARA GUARDAR EN KIT:
─────────────────────────────────────────
• Rábano (rápido, fácil)
• Espinaca (nutritiva)
• Calabaza (almacenable)
• Judías (proteína, auto-siembra)
• Maíz (calorías)
```
