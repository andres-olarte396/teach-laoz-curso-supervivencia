# CORDAJE Y CESTERÍA

**Tiempo estimado**: 90 minutos (teoría) + 120 minutos (práctica)
**Nivel**: Intermedio
**Prerrequisitos**: Módulo 1 completo

---

## ¿Por qué importa este concepto?

El cordaje es una de las tecnologías más versátiles:
- **Construcción de refugios**: Atar estructuras
- **Trampas y pesca**: Lazos, redes, líneas
- **Transporte**: Atar cargas, fabricar mochilas
- **Herramientas**: Enmangar, arcos, cuerdas de fuego

Sin cuerda, muchas técnicas de supervivencia son imposibles.

# SUBTEMA 2.4.1: EXTRACCIÓN DE FIBRAS VEGETALES

## Plantas productoras de fibra

```
PLANTAS PARA CORDAJE
═══════════════════════════════════════════

TIER 1: EXCELENTES
─────────────────────────────────────────
• ORTIGA (Urtica)
  - Fibra: Tallo exterior
  - Proceso: Secar, machacar, separar
  - Resistencia: Muy alta
  - Disponibilidad: Global templado

• LINO SILVESTRE (Linum)
  - Fibra: Tallo
  - Proceso: Enriado (remojo), machacar
  - Resistencia: Excelente
  - Disponibilidad: Europa, Norteamérica

• CÁÑAMO SILVESTRE
  - Fibra: Tallo
  - Proceso: Similar al lino
  - Resistencia: Muy alta

TIER 2: BUENAS
─────────────────────────────────────────
• CORTEZA INTERIOR (álamo, tilo, olmo)
  - Fibra: Entre corteza y madera
  - Proceso: Pelar en primavera, secar
  - Resistencia: Buena
  - Disponibilidad: Zonas templadas

• YUCA / AGAVE
  - Fibra: Hojas
  - Proceso: Machacar, raspar
  - Resistencia: Muy alta
  - Disponibilidad: Zonas áridas/tropicales

• ENEA / TOTORA (Typha)
  - Fibra: Hojas
  - Proceso: Secar, torsionar
  - Resistencia: Moderada
  - Disponibilidad: Global (zonas húmedas)

TIER 3: FUNCIONALES
─────────────────────────────────────────
• RAÍCES (de coníferas)
  - Fibra: Raíces superficiales
  - Proceso: Hervir, pelar
  - Resistencia: Buena pero rígida

• HIERBA SECA
  - Fibra: Tallos largos
  - Proceso: Torcer directamente
  - Resistencia: Baja (temporal)
```

### Procesamiento de ortiga

```
EXTRACCIÓN DE FIBRA DE ORTIGA
═══════════════════════════════════════════

1. RECOLECCIÓN
   • Cortar tallos maduros (después de floración)
   • Usar guantes (urticantes activos)
   • Elegir tallos rectos, sin ramificar

2. SECADO INICIAL
   • Secar tallos 2-3 días
   • Esto debilita el urticante
   • Tallos deben estar quebradizos

3. MACHACADO
   • Golpear tallos con piedra o mazo
   • Romper la parte leñosa interior
   • NO romper las fibras exteriores

4. SEPARACIÓN
   • Abrir el tallo longitudinalmente
   • Retirar el núcleo leñoso
   • Quedan las fibras exteriores

5. PEINADO
   • Pasar las fibras por los dedos
   • Eliminar restos de corteza
   • Resultado: Fibras largas y sedosas

    TALLO SECO → MACHACADO → SEPARADO
        │            │           │
        ▼            ▼           ▼
       ═══         ≋≋≋          │││
      (duro)     (roto)      (fibras)
```

# SUBTEMA 2.4.2: TÉCNICA DE TORCIDO INVERSO

## Fundamentos del torcido

```
PRINCIPIO DEL TORCIDO INVERSO
═══════════════════════════════════════════

El torcido inverso crea una cuerda que NO se
desenrolla bajo tensión. Esto se logra porque:

• Cada cordón individual se tuerce en una dirección
• Los cordones se envuelven entre sí en dirección opuesta
• La tensión aprieta en lugar de aflojar

    CORDÓN A →    CORDÓN B →
         ╲           ╱
          ╲         ╱
           ╲       ╱
            ╲     ╱
             ╲   ╱
              ╲ ╱
               X    ← Se cruzan
              ╱ ╲
             ╱   ╲
    CORDÓN B ←   CORDÓN A ←
    (ahora arriba)


TÉCNICA PASO A PASO:
═══════════════════════════════════════════

1. PREPARAR FIBRAS
   • Juntar fibras del grosor deseado
   • Dividir en dos grupos iguales
   • Sujetar el punto medio (o doblar un haz largo)

2. INICIO
   • Sostener el punto de inicio entre pulgar e índice
   • Un cordón arriba, otro abajo

3. TORCER
   • Torcer el cordón de ARRIBA hacia ti (horario)
   • Esto tensa las fibras

4. CRUZAR
   • Pasar el cordón torcido hacia ABAJO
   • El que estaba abajo ahora está arriba

5. REPETIR
   • Torcer el nuevo cordón de arriba
   • Cruzar
   • Continuar en ritmo constante


VISUALIZACIÓN:
─────────────────────────────────────────

   1. Inicio      2. Torcer A    3. Cruzar

      A ───         A ╲╲╲         B ───
        ╲             ╲             ╲
         ╲             ╲             ╲
      B ───         B ───         A ╲╲╲

   4. Torcer B    5. Cruzar      6. Continuar

      B ╲╲╲         A ───         A ╲╲╲
        ╲             ╲             ╲
         ╲             ╲             ╲
      A ───         B ╲╲╲         B ───


AÑADIR FIBRAS (empalme):
─────────────────────────────────────────
Cuando un cordón se acaba:
1. Introducir nuevas fibras junto a las que terminan
2. Solapar al menos 5-10 cm
3. Continuar torciendo normalmente
4. Las nuevas fibras se integran sin nudo

         ════════╲
                  ╲═════════ NUEVAS FIBRAS
         ════════╱          (solapadas)
```

# SUBTEMA 2.4.3: CESTERÍA DE ENROLLADO

## Principios de cestería

```
CESTERÍA DE ENROLLADO (COILED BASKETRY)
═══════════════════════════════════════════

La técnica más simple de cestería que no requiere
telar ni estructura compleja.

PRINCIPIO:
• Un núcleo (material grueso) forma espirales
• Una hebra (material fino) envuelve y une las espirales

MATERIALES:
─────────────────────────────────────────
NÚCLEO:
• Hierba gruesa en manojos
• Raíces
• Juncos
• Ramas flexibles

HEBRA:
• Fibras procesadas
• Tiras de corteza
• Raíces finas
• Hojas de yuca/agave


TÉCNICA BÁSICA:
═══════════════════════════════════════════

1. INICIO (base)
   • Formar pequeña espiral con el núcleo
   • Envolver con la hebra, fijando el centro

         ╭───╮
        ╱  ●  ╲
       │  ╱╲  │
       │ ╱  ╲ │
        ╲    ╱
         ╰──╯

2. PUNTADA DE ENROLLADO
   • Envolver núcleo con hebra
   • Cada 2-3 vueltas, pasar la hebra
     a través de la espiral anterior
   • Esto une las filas

   Vista de sección:

        NÚCLEO ACTUAL
            ║
        ════╬════
            ║ ← HEBRA pasa por debajo
        ════╬════    del núcleo anterior
            ║
        NÚCLEO ANTERIOR

3. FORMAR PAREDES
   • Para hacer paredes, colocar cada espiral
     encima de la anterior (no al lado)
   • Mantener tensión uniforme

4. BORDE
   • Adelgazar el núcleo gradualmente
   • Envolver completamente el final
   • Esconder la hebra en las últimas vueltas


FORMAS BÁSICAS:
─────────────────────────────────────────

PLATO:              CESTA:              BOTELLA:

    ╭─────╮         ╭─────╮         ╭───╮
   ╱       ╲       ╱       ╲       │     │
  ╱         ╲     │         │      │     │
 ╱           ╲    │         │      ╰─────╯
╱_____________╲   │         │      │     │
                  │         │      │     │
(espirales       ╰─────────╯      ╰─────╯
 horizontales)   (espirales       (estrangular
                 que suben)       en el cuello)
```

## Aplicaciones prácticas

```
USOS DEL CORDAJE Y CESTERÍA
═══════════════════════════════════════════

CORDAJE:
• Cuerdas para refugio
• Lazos de trampas
• Líneas de pesca
• Arco de bow drill
• Ataduras de herramientas
• Redes (pesca, transporte)
• Bandoleras y correas

CESTERÍA:
• Contenedores de recolección
• Trampas para peces (nasas)
• Tamices para semillas
• Cunas/mochilas
• Platos y cuencos (con recubrimiento)
• Sombreros y protección solar


RESISTENCIA DE CORDAJE:
─────────────────────────────────────────
Fibra de ortiga 2-ply: ~15-25 kg
Fibra de corteza 2-ply: ~10-15 kg
Hierba seca 2-ply: ~3-5 kg
Paracord comercial (referencia): ~250 kg
```
