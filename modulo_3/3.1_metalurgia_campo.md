# METALURGIA DE CAMPO

**Tiempo estimado**: 60 minutos
**Nivel**: Avanzado
**Prerrequisitos**: Módulo 2 completo

---

## Objetivo

Comprender los principios básicos del trabajo con metales en situaciones de supervivencia prolongada o escenarios post-colapso.

---

# SUBTEMA 3.1.1: IDENTIFICACIÓN DE METALES

```
FUENTES DE METAL EN SUPERVIVENCIA
═══════════════════════════════════════════

EN LA NATURALEZA:
─────────────────────────────────────────
• Meteoritos (hierro-níquel, muy raro)
• Cobre nativo (zonas mineralizadas)
• Oro/plata nativos (sin utilidad práctica en supervivencia)

EN ESCOMBROS/CIVILIZACIÓN:
─────────────────────────────────────────
• Vehículos abandonados (acero, aluminio)
• Estructuras metálicas
• Herramientas oxidadas
• Latas, cables, tuberías
• Clavos, tornillos, bisagras


IDENTIFICACIÓN BÁSICA:
═══════════════════════════════════════════

HIERRO/ACERO:
• Magnético (se pega a imanes)
• Se oxida (herrumbre rojiza)
• Muy duro, difícil de doblar

ALUMINIO:
• No magnético
• Muy ligero
• Blando, fácil de doblar
• No se oxida visiblemente

COBRE:
• Color rojizo/marrón
• Blando, maleable
• Se torna verde con el tiempo

LATÓN:
• Color amarillo/dorado
• Más duro que cobre
• No magnético
```

# SUBTEMA 3.1.2: FORJA IMPROVISADA

```
FORJA DE CAMPO BÁSICA
═══════════════════════════════════════════

COMPONENTES:
1. Hogar (contenedor de fuego)
2. Fuente de aire (fuelle o tubo)
3. Combustible (carbón vegetal preferido)
4. Yunque (roca plana dura)
5. Martillo (piedra o metal)

CONSTRUCCIÓN SIMPLE:
─────────────────────────────────────────

       ┌─────────────────────┐
       │    CARBÓN ARDIENTE  │
       │    ████████████████ │
       │    ████████████████ │
       └──────────┬──────────┘
                  │
              TUBO DE AIRE
                  │
    ┌─────────────┴─────────────┐
    │         FUELLE            │
    │    (bolsa + tubos)        │
    └───────────────────────────┘

TEMPERATURAS:
• Fuego normal: ~600°C
• Con fuelle constante: ~800-1000°C
• Carbón vegetal + fuelle: ~1200°C

PUNTO DE TRABAJO DEL ACERO:
• Rojo oscuro (~700°C): Difícil de trabajar
• Rojo cereza (~850°C): Trabajable
• Naranja (~950°C): Óptimo
• Amarillo (~1100°C): Riesgo de quemar


PROCESO BÁSICO:
─────────────────────────────────────────
1. Calentar metal hasta rojo cereza
2. Sacar rápidamente con tenazas
3. Golpear sobre yunque mientras está caliente
4. Recalentar cuando oscurece
5. Repetir hasta lograr forma deseada
6. Templar en agua (para acero)
```

# SUBTEMA 3.1.3: TEMPLADO Y AFILADO

```
TEMPLADO BÁSICO
═══════════════════════════════════════════

El templado endurece el acero haciéndolo útil
para herramientas de corte.

PROCESO:
1. Calentar a rojo cereza (~850°C)
2. Sumergir rápidamente en agua o aceite
3. El metal queda muy duro pero frágil
4. "Revenir" calentando a ~200°C y enfriando lento
   (hace el metal menos frágil)


AFILADO SIN HERRAMIENTAS MODERNAS
═══════════════════════════════════════════

PIEDRAS DE AFILAR NATURALES:
• Arenisca de grano fino
• Cuarcita lisa
• Pizarra (para acabado)
• Granito de grano fino

TÉCNICA:
1. Piedra gruesa: Formar el bisel (ángulo ~20°)
2. Piedra fina: Refinar el filo
3. Cuero/tela: Pulir (opcional)

ÁNGULOS DE FILO:
• Cuchillo de cocina: 15-20°
• Cuchillo de campo: 20-25°
• Hacha: 25-35°
• Machete: 20-30°

MANTENIMIENTO:
• Mantener seco para evitar óxido
• Aceitar ligeramente si hay humedad
• Reafilar cuando no corte papel fácilmente
```

## Resumen del Tema 3.1

Este tema es principalmente teórico en supervivencia de corto plazo. La metalurgia requiere recursos y tiempo que rara vez están disponibles. Sin embargo, en escenarios de supervivencia prolongada o reconstrucción, estos conocimientos son fundamentales.

**Aplicación práctica inmediata**: Reafilar herramientas encontradas con piedras naturales.
