# SUBTEMA 5.1.1: EVALUACIÓN PRIMARIA (ABC)

```
PROTOCOLO ABC
═══════════════════════════════════════════

Antes de tratar cualquier herida, verificar
que la víctima puede sobrevivir.

A = AIRWAY (Vía Aérea)
─────────────────────────────────────────
¿Está despejada la vía aérea?
• Abrir boca, revisar obstrucciones
• Inclinar cabeza hacia atrás (maniobra frente-mentón)
• Si hay obstrucción: Maniobra de Heimlich

B = BREATHING (Respiración)
─────────────────────────────────────────
¿Está respirando?
• VER: ¿Sube el pecho?
• ESCUCHAR: ¿Hay sonido de respiración?
• SENTIR: ¿Hay aliento en tu mejilla?

Si NO respira: Iniciar RCP (si estás entrenado)

C = CIRCULATION (Circulación)
─────────────────────────────────────────
¿Hay pulso? ¿Hay hemorragia grave?
• Verificar pulso en cuello (carótida)
• Buscar sangrado visible
• Hemorragia grave = PRIORIDAD INMEDIATA


ORDEN DE ACTUACIÓN:
═══════════════════════════════════════════

1. SEGURIDAD (¿es seguro acercarse?)
2. CONSCIENCIA (¿responde a estímulos?)
3. PEDIR AYUDA (si es posible)
4. ABC (Vía aérea → Respiración → Circulación)
5. TRATAR amenazas a la vida
6. Heridas secundarias
```

# SUBTEMA 5.1.2: CONTROL DE HEMORRAGIAS

```
TIPOS DE HEMORRAGIA
═══════════════════════════════════════════

ARTERIAL (GRAVE):
• Sangre roja brillante
• Sale a chorros rítmicos (pulso)
• Puede ser mortal en minutos
→ PRIORIDAD MÁXIMA

VENOSA (SERIA):
• Sangre roja oscura
• Flujo constante
• Grave si no se controla
→ PRIORIDAD ALTA

CAPILAR (MENOR):
• Sangre rezuma lentamente
• Se detiene sola normalmente
→ PRIORIDAD BAJA


TÉCNICAS DE CONTROL
═══════════════════════════════════════════

1. PRESIÓN DIRECTA
─────────────────────────────────────────
• Aplicar presión firme sobre la herida
• Usar tela limpia o mano (con guantes si hay)
• Mantener presión constante 10-15 minutos
• NO levantar para "revisar"

2. ELEVACIÓN
─────────────────────────────────────────
• Elevar extremidad por encima del corazón
• Combinar con presión directa
• Reduce presión sanguínea en la zona

3. PUNTOS DE PRESIÓN
─────────────────────────────────────────
Si presión directa no funciona,
comprimir arteria entre herida y corazón:

• Brazo: Arteria braquial (interior del brazo)
• Pierna: Arteria femoral (ingle)


4. TORNIQUETE (ÚLTIMO RECURSO)
─────────────────────────────────────────
⚠️ Solo para hemorragias que amenazan la vida
⚠️ Puede resultar en pérdida del miembro

CONSTRUCCIÓN IMPROVISADA:
• Cinturón, tela ancha, cuerda gruesa
• NUNCA alambre o cuerda fina (daña tejidos)

APLICACIÓN:
1. Colocar 5-10 cm por encima de la herida
2. Atar en nudo simple
3. Colocar palo y atar sobre él
4. Girar palo hasta que deje de sangrar
5. Fijar palo en posición
6. ANOTAR HORA de aplicación
7. NO aflojar hasta atención médica

       ┌───────────┐
       │  HERIDA   │
       └───────────┘
           ↑
       5-10 cm
           ↑
    ════●════════  ← Torniquete
        │
      PALO
    (fijado)
```

# SUBTEMA 5.1.3: INMOVILIZACIÓN DE FRACTURAS

```
SIGNOS DE FRACTURA
═══════════════════════════════════════════

• Dolor intenso localizado
• Hinchazón
• Deformidad visible
• Incapacidad de mover la zona
• Crepitación (sonido de huesos rozando)
• Posición antinatural del miembro


PRINCIPIOS DE INMOVILIZACIÓN
═══════════════════════════════════════════

1. NO intentar realinear huesos
2. Inmovilizar articulación ARRIBA y ABAJO de la fractura
3. Acolchar bien para evitar puntos de presión
4. Verificar circulación después de inmovilizar


FÉRULAS IMPROVISADAS
═══════════════════════════════════════════

MATERIALES:
• Ramas rectas y rígidas
• Tablas, cartón grueso
• Revistas enrolladas
• Bastones de senderismo
• El propio cuerpo (pierna contra pierna)

ACOLCHADO:
• Ropa, hojas, musgo
• Cualquier material blando


FÉRULA DE ANTEBRAZO:
─────────────────────────────────────────

    MANO (palma arriba)
         ↓
    ┌─────────────────┐
    │  ═══════════════│ ← Férulas (ambos lados)
    │  ═══════════════│
    └─────────────────┘
           │
        VENDAJE en 3 puntos
        (sin cubrir la fractura directamente)


CABESTRILLO:
─────────────────────────────────────────
Para fracturas de brazo, clavícula, hombro.

1. Tela triangular (camisa, bufanda)
2. Pasar bajo el brazo afectado
3. Atar detrás del cuello
4. Fijar codo con segunda vuelta al cuerpo
```

# SUBTEMA 5.1.4: TRATAMIENTO DE EMERGENCIAS TÉRMICAS

```
HIPOTERMIA
═══════════════════════════════════════════

SIGNOS (progresión):
1. Temblores, piel fría, confusión leve
2. Temblores intensos, torpeza, habla arrastrada
3. Cesa el temblor, rigidez muscular, confusión severa
4. Inconsciencia, pulso débil, respiración lenta
5. Muerte aparente

TRATAMIENTO:
─────────────────────────────────────────
1. Mover a ambiente cálido/refugio
2. Quitar ropa mojada
3. Calentar GRADUALMENTE:
   • Mantas, bolsas de dormir
   • Contacto corporal directo
   • Botellas con agua tibia en axilas/ingles
4. Bebidas calientes SI está consciente
5. NO frotar extremidades
6. NO dar alcohol
7. Buscar ayuda médica


HIPERTERMIA / GOLPE DE CALOR
═══════════════════════════════════════════

SIGNOS:
• Piel caliente, seca, roja
• Temperatura corporal >40°C
• Confusión, agitación
• Pérdida de consciencia
• Convulsiones

⚠️ EMERGENCIA MÉDICA - puede ser mortal

TRATAMIENTO:
─────────────────────────────────────────
1. Mover a la sombra/lugar fresco
2. Quitar ropa excesiva
3. Enfriar RÁPIDAMENTE:
   • Agua fría sobre el cuerpo
   • Abanicado constante
   • Hielo/agua fría en axilas, ingles, cuello
4. Si consciente: Pequeños sorbos de agua
5. Buscar ayuda médica URGENTE
```
