# SEÑALIZACIÓN Y RESCATE

**Tiempo estimado**: 60 minutos
**Nivel**: Básico-Intermedio
**Prerrequisitos**: Tema 1.1 (Fuego)

---

## Objetivo

Maximizar las probabilidades de ser encontrado por equipos de rescate utilizando señales visuales y auditivas.

---

# SUBTEMA 5.2.1: SEÑALES VISUALES

```
REGLA DE LOS TRES
═══════════════════════════════════════════

Internacionalmente, TRES de cualquier cosa
significa "EMERGENCIA / NECESITO AYUDA":

• 3 fogatas en triángulo
• 3 silbatazos
• 3 destellos de luz
• 3 columnas de humo


SEÑALES DE FUEGO
═══════════════════════════════════════════

DE DÍA: HUMO
─────────────────────────────────────────
• Humo oscuro: Añadir material verde, plástico, aceite
• Humo claro: Madera seca (contrasta con cielos oscuros)

Preparar 3 fogatas con material para humo,
listas para encender rápidamente.

         △
        ╱ ╲
       ╱   ╲
      🔥   🔥
         🔥

DE NOCHE: LLAMA
─────────────────────────────────────────
• Fuego brillante, visible a kilómetros
• 3 fogatas en triángulo si hay recursos
• Mantener material seco listo para avivar


ESPEJO DE SEÑALES
═══════════════════════════════════════════

Alcance: Hasta 50 km en condiciones ideales

TÉCNICA:
1. Crear punto de luz en tu mano
2. Extender brazo hacia el objetivo (avión, barco)
3. Mover la "V" de tus dedos hasta cubrir el objetivo
4. Mantener el destello sobre el objetivo

    SOL
     │
     │ ← Luz reflejada
     ▼
   ESPEJO
     │
     │ ← Destello dirigido
     ▼
   ✈️ OBJETIVO

ESPEJO IMPROVISADO:
• CD/DVD
• Tapa metálica brillante
• Papel aluminio sobre cartón
• Fondo de lata pulido


SEÑALES EN EL SUELO
═══════════════════════════════════════════

Para visibilidad aérea, crear símbolos grandes:
• Mínimo 3m de alto, 10m si es posible
• Contraste con el terreno
• Usar rocas, ramas, tela, cualquier material

SÍMBOLOS INTERNACIONALES:

    V = NECESITO AYUDA
    X = NECESITO ATENCIÓN MÉDICA
    I = VOY EN ESTA DIRECCIÓN →
    → = SÍGANME EN ESTA DIRECCIÓN
    LL = TODO BIEN / NO NECESITO AYUDA
```

# SUBTEMA 5.2.2: SEÑALES AUDITIVAS

```
SILBATO
═══════════════════════════════════════════

El silbato es más efectivo que la voz:
• Alcance: Hasta 1.5 km
• No agota la voz
• Sonido distintivo (no confundible con naturaleza)

CÓDIGO:
• 3 silbatazos = SOS / Emergencia
• Pausa 1 minuto
• Repetir

Incluir silbato en kit es ESENCIAL.


CÓDIGO MORSE SOS
═══════════════════════════════════════════

SOS: ··· ─── ···
(3 cortos, 3 largos, 3 cortos)

Se puede transmitir con:
• Silbato
• Linterna
• Golpes
• Espejo


VOZ
═══════════════════════════════════════════

Menos efectiva pero útil:
• Gritar "AYUDA" o "HELP"
• En series de 3
• Conservar energía entre gritos
• No gritar continuamente (agotamiento)
```

# SUBTEMA 5.2.3: ZONA DE ATERRIZAJE Y EXTRACCIÓN

```
PREPARACIÓN PARA RESCATE AÉREO
═══════════════════════════════════════════

Si esperas helicóptero, preparar zona:

ZONA DESPEJADA:
─────────────────────────────────────────
• Mínimo 25x25 metros
• Sin árboles, cables, obstáculos
• Terreno relativamente plano
• Lejos de precipicios/agua

SEÑALIZACIÓN DE ZONA:
─────────────────────────────────────────
• Marcar con "H" grande si es posible
• Señal de humo para indicar dirección del viento
• Telas brillantes en el perímetro

CUANDO LLEGA EL HELICÓPTERO:
─────────────────────────────────────────
• Quedarse en lugar visible pero alejado
• NO correr hacia el helicóptero
• Esperar señal del piloto/tripulación
• Acercarse SIEMPRE de frente (nunca por detrás)
• Agacharse al acercarse (rotores)
• Sujetar objetos sueltos (gorras, papeles)


SEÑALES PARA AVIONES
═══════════════════════════════════════════

Si un avión te sobrevuela:

NECESITO AYUDA:
• Ambos brazos levantados en Y
• O agitar tela con un brazo

         ╲ ╱
          │
         ╱ ╲
        CUERPO

ESTOY BIEN / NO NECESITO AYUDA:
• Un brazo levantado, otro hacia abajo
• Diagonal del cuerpo

         ╲
          │ ╱
         ╱ ╲
        CUERPO
```

## Resumen del Tema 5.2

**Habilidades adquiridas**:
1. Crear señales de fuego y humo
2. Usar espejo de señales
3. Crear símbolos terrestres visibles desde aire
4. Señalización auditiva con silbato
5. Preparar zona de aterrizaje

**Elemento esencial del kit**: SILBATO (10g, alcance 1.5km, no requiere baterías)
