# SUBTEMA 5.3.1: REPARACIÓN BÁSICA DE VEHÍCULOS

```
PROBLEMAS COMUNES Y SOLUCIONES
═══════════════════════════════════════════

BATERÍA DESCARGADA
─────────────────────────────────────────
Síntomas: Motor no arranca, luces débiles

Soluciones:
• Arranque con cables (si hay otro vehículo)
• Arranque empujando (solo transmisión manual)
• Esperar al sol (baterías recuperan algo de carga)

Arranque empujando:
1. Contacto en posición ON
2. Segunda marcha
3. Pisar embrague
4. Empujar hasta 15-20 km/h
5. Soltar embrague de golpe
6. Pisar acelerador cuando arranque


SOBRECALENTAMIENTO
─────────────────────────────────────────
Síntomas: Aguja en rojo, vapor del motor

Soluciones:
1. PARAR inmediatamente
2. Apagar motor, abrir capó
3. NO abrir radiador caliente (quemaduras)
4. Esperar 30+ minutos a que enfríe
5. Revisar nivel de refrigerante
6. Si hay fuga: Temporalmente usar agua

⚠️ Continuar con motor sobrecalentado
   puede destruir el motor permanentemente


PINCHAZO
─────────────────────────────────────────
Soluciones:
• Rueda de repuesto (si la tienes)
• Kit de reparación (parche + inflador)
• Si no hay repuesto: Conducir muy lento
  sobre llanta desinflada hasta lugar seguro
  (destruirá la llanta pero puede salvarte)


ATASCADO EN BARRO/NIEVE
─────────────────────────────────────────
Soluciones:
1. NO acelerar a fondo (empeora)
2. Desinflar ligeramente neumáticos
3. Colocar material bajo ruedas:
   • Ramas, tablas, piedras planas
   • Alfombrillas del coche
   • Arena, grava
4. Balancear: Adelante-atrás suavemente
5. Pala si está disponible
```

# SUBTEMA 5.3.2: GENERACIÓN DE ENERGÍA IMPROVISADA

```
FUENTES DE ELECTRICIDAD DE EMERGENCIA
═══════════════════════════════════════════

BATERÍA DE VEHÍCULO (12V)
─────────────────────────────────────────
• Puede alimentar dispositivos 12V directamente
• Adaptadores USB de coche para cargar teléfonos
• Dura horas/días según consumo

DINAMO DE BICICLETA
─────────────────────────────────────────
• Genera ~3-6W pedaleando
• Suficiente para cargar lentamente un teléfono
• Requiere regulador para no dañar dispositivos

PANEL SOLAR IMPROVISADO
─────────────────────────────────────────
Materiales de emergencia:
• Diodos de electrónica vieja (muy ineficiente)
• Paneles pequeños de calculadoras/relojes

Realidad: Sin panel solar real, la generación
solar improvisada es prácticamente imposible.


PILAS NATURALES (educativo)
─────────────────────────────────────────
Limón/patata + cobre + zinc:
• Genera ~0.5V por celda
• Corriente muy baja
• Inútil para dispositivos modernos
• Solo valor educativo


PRIORIDAD REAL:
═══════════════════════════════════════════
1. Conservar batería del teléfono (modo avión)
2. Usar cargador solar si lo tienes
3. Usar batería del vehículo + adaptador USB
4. Aceptar que la electricidad no es esencial
   para supervivencia básica
```

# SUBTEMA 5.3.3: PURIFICACIÓN DE COMBUSTIBLE

```
PROBLEMAS DE COMBUSTIBLE
═══════════════════════════════════════════

AGUA EN EL COMBUSTIBLE
─────────────────────────────────────────
Síntomas: Motor falla, no arranca

El agua se acumula en el fondo del tanque.
Solución: Drenar desde el punto más bajo
(muchos vehículos tienen tornillo de drenaje)


COMBUSTIBLE VIEJO/DEGRADADO
─────────────────────────────────────────
La gasolina se degrada en 3-6 meses.
El diésel en 6-12 meses.

Síntomas: Arranque difícil, potencia reducida

Soluciones:
• Mezclar con combustible fresco (1:1 mínimo)
• Añadir estabilizador de combustible
• En emergencia: Usar de todos modos
  (funcionará mal pero funcionará)


FILTRADO BÁSICO
─────────────────────────────────────────
Para eliminar partículas grandes:
• Filtrar a través de tela fina
• Dejar sedimentar y usar la parte superior
• NO puede eliminar agua disuelta


COMBUSTIBLES ALTERNATIVOS
═══════════════════════════════════════════

MOTORES DIÉSEL pueden funcionar con:
• Aceite vegetal (precalentado, emergencia)
• Biodiesel
• Queroseno (daña inyectores a largo plazo)

MOTORES GASOLINA:
• Muy sensibles al combustible
• No hay alternativas prácticas en emergencia
```
