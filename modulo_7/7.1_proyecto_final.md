# PROYECTO INTEGRADOR: INMERSIÓN DE 72 HORAS

**Tiempo estimado**: 8+ horas (planificación) + 72 horas (ejecución)
**Nivel**: Avanzado
**Prerrequisitos**: Módulos 0-6 completos

---

## Objetivo

Sintetizar todos los conocimientos del curso en una experiencia práctica integral que valide las competencias adquiridas.

---

# FASE 1: PLANIFICACIÓN

```
SELECCIÓN DE ESCENARIO
═══════════════════════════════════════════

OPCIÓN A: SILVESTRE (Recomendado)
─────────────────────────────────────────
• Ubicación: Zona natural a 30+ min de civilización
• Duración: 48-72 horas
• Nivel: Intermedio-Avanzado
• Requisitos: Permiso de acampada, clima favorable

OPCIÓN B: SEMI-SILVESTRE
─────────────────────────────────────────
• Ubicación: Camping o zona recreativa
• Duración: 48 horas
• Nivel: Básico-Intermedio
• Requisitos: Acceso a ayuda si es necesario

OPCIÓN C: URBANO (Alternativa)
─────────────────────────────────────────
• Ubicación: Tu hogar simulando corte de servicios
• Duración: 72 horas
• Nivel: Básico
• Requisitos: Desconectar electricidad, agua, gas


NIVELES DE DIFICULTAD
═══════════════════════════════════════════

NIVEL BÁSICO:
─────────────────────────────────────────
• Kit completo permitido (BOB)
• Comunicación de emergencia disponible
• Zona conocida
• Duración: 24-48 horas
• Check-in cada 12 horas

NIVEL INTERMEDIO:
─────────────────────────────────────────
• Kit mínimo (10 items)
• Comunicación limitada
• Zona semi-conocida
• Duración: 48-72 horas
• Check-in cada 24 horas

NIVEL AVANZADO:
─────────────────────────────────────────
• Solo cuchillo y ropa
• Solo comunicación de emergencia real
• Zona desconocida
• Duración: 72+ horas
• Posición GPS compartida por seguridad
```

# FASE 4: ANÁLISIS POST-ACCIÓN

```
INFORME FINAL (After Action Report)
═══════════════════════════════════════════

1. RESUMEN EJECUTIVO
─────────────────────────────────────────
• Duración real
• Condiciones enfrentadas
• Resultado general (éxito/parcial/fracaso)

2. TÉCNICAS APLICADAS
─────────────────────────────────────────
Por cada módulo del curso:
• ¿Qué técnicas usaste?
• ¿Funcionaron como esperabas?
• ¿Qué modificaciones hiciste?

3. PROBLEMAS Y SOLUCIONES
─────────────────────────────────────────
Para cada problema:
• Descripción del problema
• Cómo lo identificaste
• Solución aplicada
• Resultado
• Qué harías diferente

4. GESTIÓN DE RECURSOS
─────────────────────────────────────────
• ¿Qué items de tu kit usaste?
• ¿Qué items no usaste?
• ¿Qué te faltó?
• ¿Qué sobró?

5. ESTADO FÍSICO Y MENTAL
─────────────────────────────────────────
• Gráfico de evolución (1-10)
• Momentos críticos
• Estrategias de afrontamiento
• Impacto del aislamiento

6. LECCIONES APRENDIDAS
─────────────────────────────────────────
• Top 5 aprendizajes
• Errores a evitar
• Técnicas a profundizar
• Cambios para futuras experiencias

7. RECOMENDACIONES
─────────────────────────────────────────
• Para ti mismo
• Para otros estudiantes
• Para el diseño del curso


DOCUMENTACIÓN VISUAL
═══════════════════════════════════════════

□ Fotos de refugio construido
□ Fotos de fuego/hogar
□ Fotos de fuentes de agua
□ Fotos de alimentos obtenidos
□ Fotos de herramientas fabricadas
□ Video resumen (opcional)
```

```

─────────────────────────────────────────

─────────────────────────────────────────

─────────────────────────────────────────

─────────────────────────────────────────

NAVEGACIÓN (10%)

□ Ruta de extracción conocida

DOCUMENTACIÓN (10%)
─────────────────────────────────────────
□ Diario completo
□ Fotos de calidad
□ Análisis post-acción profundo

NIVEL PLATA:
• Completar 48+ horas

NIVEL ORO:
• Completar 72+ horas
```

## Consejos finales

```
ANTES DE PARTIR
═══════════════════════════════════════════

1. Comunica tu plan a alguien de confianza
2. Verifica el pronóstico del tiempo
3. Conoce tus límites
4. Lleva siempre método de comunicación de emergencia
5. Establece límites claros para abortar

DURANTE LA EXPERIENCIA
═══════════════════════════════════════════

1. La seguridad es prioridad absoluta
2. No hay vergüenza en abortar si es necesario
3. Documenta todo, incluidos los fracasos
4. Mantén actitud de aprendizaje
5. Disfruta el proceso

DESPUÉS
═══════════════════════════════════════════

1. Celebra tu logro
2. Descansa y recupera
3. Procesa la experiencia
4. Comparte aprendizajes
5. Planifica la siguiente
```
